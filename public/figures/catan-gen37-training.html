The recorded update was Gen36 → games → training → Gen37. Gen37’s own final weights were not used to generate the games that trained Gen37.

Scroll sideways to follow the full training loop.

Inside one search: many hypothetical continuations

Start at the current position → investigate a root action → follow decision and chance nodes → evaluate a new leaf with the frozen GNN → carry its value back up the visited path.

Across games: learning from the collected targets

Run a fresh forward pass on stored observations → compare predictions with targets → backpropagate the loss → let AdamW change the weights. Search is not rerun inside this gradient step.

Opponent selection was weighted 75% current-model mirror and 25% frozen exploiter33. This is the recorded generation’s setup, not a claim that every earlier generation used the same settings.
